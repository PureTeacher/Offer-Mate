# 择途

在当下就业竞争激烈、赛道选择多元、职业迷茫频发的时代背景下，青年群体专业抉择、就业择业、生涯规划等问题愈发突出。传统职业规划存在收费高昂、资源闭塞、指导片面、针对性弱、规划周期滞后等痛点。**择途**，一款高效、全面、智能、专属的 AI 职业规划助手，应运而生。平台前端基于 Vue 技术栈与 UniApp，搭配云端服务，打造 AI 智能咨询、职业综合测评、行业科普知识库、专业导师预约四大核心功能，构建起「认知 - 测评 - 规划 - 指导」全链条生涯服务体系。

## 一、安全登录注册体系，筑牢账号第一道防线

择途搭建完善的登录注册功能，支持手机号快捷注册与登录，同步加入手机号有效性校验等智能判断机制，杜绝无效账号注册，保障注册流程高效合规。贴心设置找回密码功能，用户可通过绑定手机号接收验证码，快速重置登录密码，解决账号遗忘难题。专属个人信息管理模块与登录日志功能相配合，可随时查看账号登录历史记录，全方位守护账号与个人生涯信息安全。

## 二、24 小时 AI 智能咨询，生涯困惑随时解答

择途深度集成阿里云通义千问大模型并完成职业赛道专项参数优化，提供全天候不间断 AI 陪伴咨询。贴合升学选专业、实习求职、转行跨界、技能提升等真实生涯场景，搭配定制化系统提示词与专业解答模板，打造客观严谨、贴合就业现状的智能规划顾问形象。核心升级对话总结功能，自动梳理用户核心困惑、诉求与发展短板，精准定位生涯难题；同时完整保留 AI 咨询历史记录，用户可随时回溯问答内容、复盘规划思路，让智能咨询既有即时答疑，又有长期规划参考依据。

## 三、专业职业综合测评，发展数据全程可追溯

想要科学认清自我优势、找准适配赛道？平台整合职业定位自测，职业目标可行性评估，职业竞争力评估，职业成长空间评估，核心职业技能测评，职业发展准备度测评，职业转型风险评估等 7 类权威测评量表，覆盖性格特质、能力短板、职业倾向、行业适配、发展潜力等多维度评估。用户仅需 3-5 分钟即可完成全套职业体检，系统通过标准化数据运算，自动生成含综合评分、适配岗位推荐、发展等级评级与个性化提升方案的专业测评报告。支持历史测评记录一键查阅，直观对比不同阶段自我认知与职业倾向变化，助力用户精准定位方向、提前规避发展误区。

## 四、多元行业科普赋能，夯实生涯发展基础

职业知识科普模块持续迭代优化，涵盖热门行业解析、专业学习指南、求职面试技巧、证书报考攻略、职场生存法则五大类优质内容，全部由职业规划师、行业资深从业者、就业指导老师联合编撰审核。内容采用简洁直观的卡片式布局呈现，方便用户利用碎片化时间快速积累行业认知、学习求职干货、补齐能力短板，全面提升自主规划与职场适应能力。

## 五、精准导师预约服务，专业指导高效触达

当用户需要深度定制化生涯方案、一对一针对性指导时，专业生涯规划导师团队在线待命。预约服务全面升级，支持查看导师从业资历、擅长领域、辅导方向与成功案例，用户可结合自身需求精准匹配升学、校招、转行、考研等专项导师；同步新增预约历史记录功能，留存过往一对一辅导详情与定制方案，方便用户复盘规划内容、稳步落地成长计划。

## 六、个性化个人中心，全量功能一键管理

个人中心界面精细化划分五大功能分区，简洁高效、操作便捷：

1. **账号管理**：支持头像上传、昵称修改、注册邮箱绑定与变更、手机号验证及更换，自由完善个人专属资料；
2. **密码修改**：搭载密码强度实时检测功能，引导用户设置高强度安全密码，多重保障账号隐私安全；
3. **设置中心**：隐私设置可自主管控测评数据、个人规划报告、资料信息的展示权限；通知设置可灵活开启测评提醒、预约通知、行业资讯推送；支持字体大小调节，适配多人群使用习惯；同步开放隐私政策、用户协议查阅入口，权限与使用体验全权由用户自主掌控；
4. **帮助与反馈**：支持按功能故障、优化建议、咨询求助分类提交反馈，内置修改资料、账号问题、报告导出、预约流程等高频问题自助解答，高效解决使用难题；
5. **关于我们**：清晰展示应用名称、版本信息、核心服务介绍，附带官方沟通渠道，充分保障用户知情权与服务权益。
